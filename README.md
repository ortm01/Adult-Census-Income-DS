# Предсказание дохода: бустинги, ансамбли, калибровка

Бинарная классификация на датасете Adult Census Income (32 537 строк после удаления дубликатов, доля положительного класса 24,1%). Цель проекта: сравнить модели, проверить, даёт ли ансамбль выигрыш над лучшей одиночной моделью, и корректно оценить качество без утечки данных.

Источник данных: `https://www.kaggle.com/datasets/priyamchoksi/adult-census-income-dataset`

## Результаты

Тест: 6 508 строк (20%, стратифицированное разбиение). Baseline (всегда «0»): accuracy 0,759.

**Одиночные модели**

| Модель | ROC AUC (CV при подборе) | ROC AUC (тест) |
|---|---|---|
| XGBoost | 0,9281 | 0,9267 |
| LightGBM | 0,9269 | 0,9263 |
| CatBoost | 0,9265 | 0,9250 |
| Random Forest | 0,9174 | 0,9168 |
| Logistic Regression | 0,9012 | 0,9015 |

**Ансамбли (тест)**

| Вариант | ROC AUC | LogLoss | Brier |
|---|---|---|---|
| XGBoost | 0,9267 | 0,2811 | 0,0891 |
| Среднее XGB + LGB + Cat | 0,9267 | 0,2879 | 0,0914 |
| Стекинг (логистическая регрессия) | 0,9270 | 0,2809 | 0,0891 |
| Взвешенное геометрическое среднее | 0,9268 | 0,2827 | 0,0897 |

**Финальная модель: XGBoost**, порог 0,41 (выбран по F1 на OOF): accuracy 0,866, precision 0,718, recall 0,731, F1 0,724, PR AUC 0,827.

## Выводы

1. Ансамбль не дал значимого прироста. Стекинг выше XGBoost на 0,0003 AUC при разбросе по фолдам около ±0,0015. XGBoost и LightGBM почти копии (корреляция предсказаний по Спирмену 0,996), остальные модели слабее и ошибаются похоже.
2. Простое среднее ухудшает вероятности при том же AUC (LogLoss 0,2879 против 0,2811). Причина: CatBoost обучен с `auto_class_weights`, его вероятности завышены (среднее предсказание 0,353 при реальной доле 0,241).
3. Sigmoid-калибровка по OOF вернула CatBoost и Random Forest к честной шкале: LogLoss 0,343 → 0,283 и 0,357 → 0,298 при неизменном AUC. XGBoost, LightGBM и Logistic Regression в калибровке не нуждались.
4. Optuna оптимизировала AUC, который не чувствителен к калибровке, поэтому выбор `class_weight` не учитывал искажение вероятностей.

## Методология

- Препроцессинг: `TargetEncoder` для категориальных признаков, обучается внутри каждого фолда (без утечки таргета).
- Подбор гиперпараметров: Optuna (TPE, seed 42), 3-fold CV по ROC AUC, число деревьев определяется ранней остановкой. 13-18 попыток на модель.
- OOF-предсказания: 5-fold, все модели обучаются заново в каждом фолде вместе с препроцессингом.
- Выбор ансамбля: Optuna выбирает среди пяти видов (среднее по подмножеству, взвешенное, ранговое, геометрическое, стекинг) и подбирает их параметры по OOF. Стекинг оценивается вложенной кросс-валидацией.
- Калибровка (sigmoid и isotonic) обучается на OOF и оценивается кросс-валидацией.
- Порог классификации выбирается по F1 на OOF. Тест не участвовал в выборе моделей, ансамбля и порога.

## Ограничения

- Мало попыток Optuna (13-18 на модель) из-за времени обучения.
- Ранняя остановка идёт по AUC, а не по LogLoss.
- Различия между XGBoost, LightGBM, CatBoost и стекингом сопоставимы с шумом, тест содержит 6 508 строк.
- Признаки `sex` и `education` исключены из модели.
